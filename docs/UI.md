# UI 设计

来源：xudong7587/sunny-ui-design-system，晴蓝 blue + 精致描边 outline。按其设计规范映射到 Android 原生控件；不依赖 React 或 WebView，未复制组件/CSS 源码。

- 首页：两个可聚焦按钮，选择 HDMI 通道、更多设置；其余为不可交互说明和真实授权状态。
- 默认深色：主色 #9dbbff，深蓝灰底 #111821，焦点底 #263a56，正文 #edf0f6，辅助 #a7b1c0。
- 静止细描边，焦点 3dp 蓝色轮廓，按下加深底色；遥控器左右切换，无装饰性缩放动画。
- 通道选择、设置、权限、备用连接及诊断沿用同一表面语言，返回键逐级返回。
- HDMI 3 的既有配置保留；其他通道未校准时不会转发。

深色界面已获用户确认，随 v0.4.1 发布。预览页是按原生布局复现的浏览器交互稿，不代表电视实机截图；APK 仍需安装后验证排版与遥控焦点。
